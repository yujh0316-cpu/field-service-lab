# Field Service Lab

ASML 중심의 한국어 반도체 장비 CS 진단 훈련입니다. ASML TWINSCAN NXT:2000i(DUV), NXE:3600D(EUV), TEL LITHIUS Pro Z(포토 트랙)의 공개 제품 개요를 참고하고, 기존 PECVD/PVD 교육 모델을 함께 제공합니다.

장비별로 계통도, 계측값, 점검 단서와 조치가 달라집니다. DUV는 정렬·초점·액침·노광량, EUV는 진공·광원·스테이지·열 안정화, 포토 트랙은 도포·베이크·현상을 연습합니다. 제조사 공식 서비스 도구가 아니며, 알람 코드·수치·허용 범위·고장 사례는 가상 훈련 설정입니다.

## 코드 읽는 순서

각 코드 파일에는 한국어 주석이 있습니다. 주석은 `//`(JavaScript), `/* ... */`(CSS), `<!-- ... -->`(HTML) 형태이며, 바로 아래 코드가 담당하는 역할을 설명합니다. `.openai/hosting.json`은 JSON 규격상 주석을 사용할 수 없는 배포 설정 파일입니다.

1. `dist/index.html`: 화면의 뼈대입니다. 상단 메뉴, 오류 목록, SVG 장비 구조도, 계측 카드, 진단 영역이 배치됩니다. `id`는 JavaScript가 요소를 찾는 이름이고, `class`는 CSS 디자인을 연결하는 이름입니다.
2. `dist/style.css`: 색상, 간격, 글꼴, 버튼과 경보 표시를 정의합니다. 맨 위 `:root`에 공통 색상이 있으며, 아래쪽 `@media`는 화면 크기에 따른 배치를 정합니다.
3. `dist/equipment-data.js`: 장비 소개, 공개 자료 링크, 노광·포토 장비의 시나리오와 원인 변형을 정의합니다.
4. `dist/equipment-view.js`: 선택한 장비의 소개와 기능 연결도를 그립니다.
5. `dist/service-console.js`: Service Ticket, 공정 Trend, 장비 이력, Fault Tree, Escalation 근거와 서비스 리포트를 생성합니다.
6. `dist/app.js`: 기존 증착 시나리오와 공통 동작을 정의합니다. 각 구역과 주요 함수 위에 한국어 설명이 있습니다. 상태에 따라 바뀌는 체크리스트와 결과 화면의 HTML은 이 파일 안에서 생성됩니다.

### 주요 동작 따라가기

`inject()` 오류 발생 → `ack()` 알람 확인 → `check()` 점검 → `applyAction()` 원인·조치 판정 → `verify()` 복구 검증 순서입니다. `state`는 진행 상태를 보관하고, `render()`는 그 상태를 화면에 반영합니다.

`scenarios`에서 문제 내용을 수정할 수 있습니다. `causes`와 `actions`는 선택지이며, `variants`의 `cause`와 `action`은 정답의 배열 번호입니다. 번호는 0부터 시작합니다. `results`는 점검 결과, `lesson`은 성공 후 해설입니다.

HTML이 CSS와 네 JavaScript 파일을 순서대로 연결합니다. `dist` 안의 파일을 함께 보관하세요. 브라우저에서 `index.html`을 열면 실행되며 코드를 읽거나 수정할 때는 텍스트 편집기를 사용합니다.

동작 검증은 프로젝트 폴더에서 `node verify.mjs`로 실행합니다. 다섯 장비 모드의 원인 변형, 교차 장비 면접 3개와 복합 원인 Case를 포함한 50개 훈련 흐름을 검사합니다. 면접 점수, 정보 요청 비용, 3-Case 랜덤 세션, 잘못된 원인·조치, 장비 전환 제한, 교차 계측의 복구 전후 값, 가상 데이터 표시도 검증합니다.

## 교차 장비 CS 면접 연습

장비 선택 후 왼쪽 목록의 ‘교차 장비’ Case를 접수합니다. 접수 장비가 실제 원인 장비라는 뜻은 아닙니다.

| 선택 모드 | 사례 | 구분할 원인 |
| --- | --- | --- |
| DUV | DUV 후 CD 편차 | 트랙 PEB 온도 불균일 / DUV 노광량 / PECVD 하부막 |
| EUV | EUV 노광 후 CD 이상 | EUV 에너지 전달 / 트랙 현상 / PECVD 하부막 |
| 포토 트랙 | DUV/EUV 공통 패턴 편차 | PECVD 유량 분포 / 트랙 도포 / DUV·EUV 초점 |

각 사례에 경보, 장비 간 계측 스냅샷, 3단계 점검, 원인·조치 선택, 오답 및 완료 피드백, 가상 재시험 결과가 있습니다. 교차 시험에서 통제한 조건과 다른 장비를 배제하는 근거를 면접 답변으로 설명하세요. 완료 후 서비스 리포트에도 피드백이 포함됩니다. 모든 수치·기준·알람·시험 결과는 **교육용 가상 데이터**이며 제조사 사양이나 실제 정비 절차가 아닙니다. DUV/EUV 간에는 절대 CD가 아닌 각 공정의 기준 대비 편차를 비교합니다.

면접 모드를 켜면 필요한 정보 요청마다 가상 시간 비용이 부과되고, 최소 두 개의 증거로 판단할 수 있습니다. 가설·핵심 근거·다른 장비 배제·다음 조치를 작성하고 생산 HOLD 및 에스컬레이션 방식을 선택하면 진단 30점, 증거 효율 15점, 답변 구조 20점, 고객 대응 20점, 시간 15점으로 평가합니다. ‘3-Case 랜덤 면접’은 서로 다른 장비의 Case 세 개를 이어서 출제하고 평균 점수를 보여줍니다. EUV 복합 이상 Case는 단일 부품을 성급하게 확정하지 않고 노광 에너지와 PEB 대기 시간을 분리 시험하도록 설계했습니다.

`dist/index.html`을 브라우저로 열거나 `node preview-server.mjs` 실행 후 표시되는 주소로 접속합니다. 웹 폰트와 제조사 제품 사진을 외부에서 불러옵니다. 로딩에 실패해도 대체 글꼴과 제조사 링크로 훈련을 계속할 수 있습니다.

장비 선택 → Case 접수 → Alarm acknowledge → 증거 수집 → Root Cause와 Corrective Action 선택 → Verification → 서비스 리포트 생성 순서입니다. DUV 4개, EUV 4개, 포토 트랙 3개 증상에 각각 두 원인 변형이 있습니다. 증착 공통 6개 증상은 PECVD/PVD 각각에서 두 원인 변형을 연습합니다. Service Ticket, 공정 Trend, Fault Tree, 장비 이력, Escalation 준비도와 텍스트 보고서 저장을 지원합니다.

모든 구조, 알람 코드, 수치, 허용 범위, 시험 결과 및 점수는 교육용 설정입니다. 알람 계측값은 트립 당시 스냅샷이며 공정은 보호 정지됩니다. 정비 성공 후 별도 재시험으로 복구됩니다. 실제 정비·안전 격리는 실행하지 않고 승인 절차를 거친 것으로 모사합니다. 새로고침 시 기록이 초기화됩니다.

화면의 ‘학습 자료’에 원리 근거를 연결했습니다. 개별 시나리오는 제조사 매뉴얼의 직접 인용이 아닙니다. 게이트 밸브 및 히터 사례는 일반 제어 진단에 기초한 가상 훈련입니다.
